# \# Antigravity Multiagents Starterpack Scaffolder

# 

# This extension instantly scaffolds a complete AI Agents Orchestrator environment. 

# 

# \## Features

# \* Automatically generates the predefined agent architecture.

# \* Creates directories for PM Orchestrator, Frontend, Backend, QA, Analyst, UI/UX, and Architect agents.

# \* Safe initialization: Prevents accidental overwrites of existing workspaces.

# 

# \## Usage

# 1\. Open an empty folder in VS Code.

# 2\. Open the Command Palette (`Ctrl + Shift + P`).

# 3\. Run `AI Agents: Initialize Project`.
